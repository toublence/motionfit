# 실시간 음성 코칭 분석 — 2026-07-22

## 실측 조건

- 기기: Samsung Galaxy S24+ (`SM-S926N`), 전면 카메라, USB 연결
- 세션: 2026-07-22 16:16:21~16:17:43, 스쿼트 10회
- 근거: 기기 `motionfit.db`의 반복별 분석 결과와 Android TTS 시작/완료 로그

## 발견한 오판

1. 8회차는 깊이 점수가 100점이면서 `insufficientDepth`가 함께 저장됐다. 최저 무릎각으로 점수를 만들고, 최저점 주변 여러 프레임의 위반 비율로 문제를 확정해 서로 모순됐다.
2. 10회 중 8회에 `incompleteLockout`이 기록됐다. 카운터는 최저점에서 명확히 회복하면 완전 기립 전에 반복 trace를 닫으므로, 해당 trace로 완전 기립 실패를 판단할 수 없다.
3. 같은 촬영 위치인데 반복별 camera angle이 `front`와 `oblique`로 흔들렸다. 그 결과 깊이·뒤꿈치와 무릎·균형의 관찰 가능 여부가 반복마다 바뀌었다.
4. 뒤꿈치는 바닥 기준이 아니라 발끝과 뒤꿈치의 한 프레임 높이 차이, 무릎 정렬은 발끝과 무릎의 절대 가로 차이를 사용했다. 체형·스탠스·원근 차이가 자세 문제로 잘못 분류될 수 있었다.
5. 9.1초 반복처럼 추적 공백 가능성이 큰 trace도 속도 문제로 확정됐다.
6. TTS는 정상 동작했지만 숫자 읽기와 모든 안내가 같은 피치·속도여서 운동 리듬감이 약했다.

## 적용한 수정

- 최저점의 가장 깊은 40% 관절각 하나로 깊이 점수와 문제 여부를 함께 계산한다.
- MediaPipe world landmark가 있으면 3D 무릎·고관절·상체 각도를 우선 사용한다.
- 촬영 각도는 캘리브레이션 결과를 세션 중 유지한다.
- 뒤꿈치·무릎 정렬·균형은 서 있는 캘리브레이션 값에서 변한 양만 평가한다.
- 350ms보다 긴 프레임 공백이 있으면 해당 반복의 속도·제어는 평가하지 않는다.
- 완전 기립은 현재 trace에서 관찰 불가로 처리해 거짓 코칭을 막는다.
- 자세 문제는 최근 3회 중 2회 이상 관찰될 때 코칭하고, 안전 관련 고신뢰 문제만 즉시 안내한다. 같은 내용은 최소 3회를 띄운다.
- 한국어 카운트는 `하나!`, `둘!`처럼 말하고, 카운트·격려는 조금 빠르고 높은 피치, 자세 교정은 안정된 속도와 피치로 말한다.

## 수정 빌드 재검증

- 16:28:34~16:29:36에 10회 모두 카운트되고 `하나!`~`열!` 음성이 각각 약 0.5~0.8초에 완료됐다.
- 정상 자세로 판정된 1~7회와 10회에는 자세 교정이 한 번도 나오지 않았다.
- 8회에는 `insufficientDepth`, `excessiveTorsoLean`이 신뢰도 0.79로 한 번만 관찰됐고, 9회에는 별개의 `unstableControl`만 관찰됐다. 반복 근거가 없으므로 확정 코칭을 보류했다.
- 기존에 거의 모든 반복에서 발생한 `incompleteLockout`, 정상 속도 반복의 `ascentTooFast`, 기준 없는 `heelLift` 오판은 재현되지 않았다.
- 최종 세트에서 세트 완료와 운동 완료가 연속 재생된 것을 추가로 발견해 최종 세트는 운동 완료만 안내하도록 수정했다.

## 2차 실기기 재검증과 추가 수정

- 기존 빌드에서 운동 시작 직후 수행한 2~3회는 1.5초/20프레임 캘리브레이션이 끝나기 전이라 누락됐다. 기준 수집을 0.3초/6프레임으로 줄이고, 사용자가 움직여도 이미 모은 서 있는 기준 프레임을 버리지 않게 수정했다.
- 수정 빌드 신규 세션에서 첫 동작부터 `하나`, `둘`, `셋`이 모두 기록됐다.
- 숫자 TTS는 판정 로그 이후 약 0.005~0.13초 안에 실제 발화를 시작했다.
- 재생 중인 낮은 우선순위 안내·격려가 숫자를 지연하지 않도록 카운트가 기존 음성을 중단하고 선점하게 수정했다.
- 발목이 없는 반복도 깊이를 미평가하지 않고 골반 하강량으로 평가했다. 무릎 정렬은 발끝 대신 서 있을 때의 골반 대비 무릎 간격 변화를 사용한다.
- 상체 숙임이 2회 연속 관찰된 뒤 상체 교정이, 무릎 모임이 2회 연속 관찰된 뒤 무릎 교정이 각각 카운트 직후 재생됐다.
- 여러 문제를 일부러 계속 만들었을 때 서로 다른 교정이 매 반복 번갈아 나오는 현상을 확인해 모든 자세 코칭 사이에 최소 한 번의 무음 반복을 둔다.
- 세트 마지막 반복의 자세 교정이 휴식 안내 뒤에 늦게 재생되는 문제를 제거하고, 한국어 교정 문장을 더 짧은 운동형 문장으로 다듬었다.
